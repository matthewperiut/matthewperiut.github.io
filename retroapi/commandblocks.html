Command blocks

All three, with modern's modes, modern's editor and modern's chain behaviour.

Ported from modern Minecraft, including the rule that decides what a command block is: the mode is not a setting stored on the block, it is which of three blocks you placed. Retyping one in the editor swaps the block and keeps the facing.

BlockModeRuns
minecraft:command_blockImpulseonce, on the rising edge of a redstone signal
minecraft:repeating_command_blockRepeatevery tick while powered, or always if set to Always Active
minecraft:chain_command_blockChainwhen the block pointing into it succeeds, in the same tick

They register under minecraft:, not RetroAPI's namespace. They are vanilla blocks beta happens not to have yet, and a world that later moves to a version which does have them should find its command blocks already under the right name.

Getting one

There is no recipe, exactly as on modern. /give <player> minecraft:command_block, or the Operator Utilities tab of the creative inventory. Only a creative player can open the editor.

The editor

Modern's screen, at modern's geometry: the command field, then three buttons across the bottom.

ButtonValues
ModeImpulse / Chain / Repeat, which swaps the block
ConditionUnconditional, or Conditional: only run if the block behind succeeded
RedstoneNeeds Redstone, or Always Active
O / Xtrack output, which fills Previous Output

Chains

A chain block runs when the block pointing into it succeeds, and the walk continues while the next block along is also a chain block, re-reading each block's facing so a chain can turn corners. Length is capped by the maxCommandChainLength game rule, and a block may only run once per tick, so a chain that loops back on itself stops instead of hanging the game.

Where the settings live

Beta's block metadata is entirely spent on which way the block faces, so Conditional and Always Active ride on the block-data API, RetroAPI's per-position int store. The command text itself is on the block entity, because that store holds numbers and a command is a string.

CommandBlocks.isConditional(world, x, y, z);
CommandBlocks.setAuto(world, x, y, z, true);

if (world.getBlockEntity(x, y, z) instanceof CommandBlockEntity block) {
	block.setCommand("say hello");
}

What a command block runs as

Modern's source: named @, positioned at the block, permission level 2, with no entity. That is what makes @p mean "nearest to the block" and ~ ~ ~ mean the block's own coordinates.

Commands worth pairing them with

/setblock <pos> <block> [destroy|keep|replace] and /fill <from> <to> <block> [destroy|hollow|keep|outline|replace], both ported with modern's modes. See Commands.
